## SQL
- SQL stands for Structured Query Language
- It is a standard language used to interact with relational databases
- Relationa means data table k form me
- Using SQL, we can create, read, update, delete, and manage data stored in a relational database
- C++ → programming language
- `SQL` → `database query language`
```txt
    Application
        ↓
    SQL
        ↓
    Database (MySQL / PostgreSQL / etc.)
        ↓
    Data

```
- MySQL / PostgreSQL : Ye Database Management Systems (DBMS) hain jo SQL ko use karte hain
- SQL is the language you speak, while MySQL and PostgreSQL are the systems that understand that language and manage your data
